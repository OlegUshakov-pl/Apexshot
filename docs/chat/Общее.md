Простейший способ — отправить модели структурированную инструкцию.
Пример prompt:
```
Ты — ассистент, который создаёт компактные структурированные слепки веб-контента.
Сгенерируй JSON по схеме.
Не выдумывай факты.
Используй только предоставленный текст.
Если чего-то нет, оставь поле пустым или null.
Верни только JSON без пояснений.

Схема:
{
"source_url": string,
"source_title": string,
"summary": string,
"key_points": array of string,
"entities": array of string,
"claims": array of {text: string, evidence: string, confidence: number},
"questions": array of string,
"topics": array of string
}

Текст:
{document_text}

```

### Промпт для Ollama

```
Ты — инженер-индексатор машиночитаемых AI-слепков.
Твоя задача: по одному источнику сформировать короткий, точный, машинно проверяемый JSON-файл.

Требования:
1. Опирайся только на предоставленный текст.
2. Не добавляй информацию из своих знаний, если она явно не присутствует в тексте.
3. Каждое fact должно иметь поле quote. Это цитата из исходного текста.
4. Если информации не хватает, ставь null или empty list.
5. summary должен быть кратким, без рекламного тону.
6. keywords и entities должны быть полезны для поиска.
7. confidence — степень уверенности в корректности суммаризации, от 0.0 до 1.0.
8. Ответ — только один JSON-объект, без markdown, без пояснений.

```

### Промпт для генерации слепок

Ты создаешь ИИ-слепок — маленький файл с обобщенной информацией о тексте.

Верни только валидный JSON без пояснений и без markdown.

Схема:
{
"summary": "120-200 слов, только факты из предоставленного текста",
"key_facts": ["5-10 коротких фактов"],
"entities": {
"people": [],
"orgs": [],
"topics": [],
"places": []
},
"questions": ["3-5 вопросов, на которые текст отвечает или которые он ставит"],
"tags": ["3-8 коротких тегов"],
"confidence": 0.0
}

Правила:
- используй только предоставленный текст;
- не выдумывай факты;
- если информации не хватает, оставь соответствующие поля пустыми;
- confidence — от 0 до 1, насколько точно и полно удалось обобщить текст;
- сохраняй важные детали, цифры, условия, ограничения;
- если текст рекламный или неполный, понизь confidence.

Текст:
{TEXT}
