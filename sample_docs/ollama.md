# Ollama — локальные LLM

Ollama — популярный способ запускать локальные LLM прямо на компьютере.
Проект позволяет скачивать модели и обращаться к ним по HTTP API на порту 11434.

## Возможности

- Загрузка моделей по тегам, например `llama3.1:8b`.
- REST API `/api/chat` и `/api/generate`.
- Настраиваемые параметры: temperature, top_p, seed, num_predict.

Локальные LLM помогают сохранить приватность данных, потому что текст не покидает машину.

## Установка

Достаточно установить приложение и выполнить `ollama pull llama3.1:8b`.
