# Поиск по слепкам

Библиотека слепков хранит маленькие JSON-файлы и индекс SQLite FTS5.
Поиск выполняется по заголовкам, фактам, тегам и вопросам.

FTS5 использует ранжирование по rank, а если расширение недоступно,
приложение переключается на LIKE-запросы.

Каждый факт в слепке содержит цитату из исходного текста.
Если цитата не найдена в корпусе, уверенность снижается на 0.2.
